texconv.exe — Microsoft DirectXTex (https://github.com/microsoft/DirectXTex)

Используется для конвертации текстур камуфляжей: DDS (BC1/BC3) → PNG для миниатюр
и любая картинка → DDS при замене. Лицензия MIT, © Microsoft Corporation.
Файл кладётся рядом с программой в папку tools и включает установщик.
